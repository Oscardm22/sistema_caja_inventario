# Sistema de Caja e Inventario

Sistema web para gestión de caja, inventario y ventas desarrollado con PHP, MySQL y Tailwind CSS.

## 🚀 Características

- ✅ Sistema de autenticación con roles (admin y cajero)
- ✅ Gestión de caja (apertura, cierre, movimientos)
- ✅ Control de inventario (productos, categorías, stock)
- ✅ Módulo de ventas con facturación
- ✅ Gestión de clientes
- ✅ Reportes y estadísticas
- ✅ Diseño responsive con Tailwind CSS
- ✅ Base de datos MySQL

## 🛠️ Tecnologías

- PHP 8.2+
- MySQL
- Tailwind CSS 3.x
- Font Awesome 6.x
- XAMPP (entorno local)

## 📋 Requisitos Previos

1. XAMPP o WAMP instalado
2. PHP 8.2 o superior
3. MySQL 5.7 o superior
4. Git (para control de versiones)
